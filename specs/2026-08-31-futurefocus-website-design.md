# Futurefocus Solutions — Website Design Spec

Date: 2026-08-31
Status: Approved by user in chat (theme direction, placeholder handling, EMAIL token, fonts)

**2026-08-31 addendum — build system.** The original plan (§2) shipped `{{TOKEN}}` placeholders directly in deployed HTML for a hypothetical later injection step. That's been superseded: the site is now generated by `build.py` from a single `business.json` (modeled on a prior working site, `Archive/Amber Consultants/site`) — edit `business.json`, run `python3 build.py`, and every page regenerates with real data baked in and correct relative paths for its folder depth. Source of truth for page content is now `pages/*.html` (fragments with `{{TOKEN}}`/`{{#FIELD}}` markers still intact); the root-level `index.html`, `about/index.html`, etc. are build **output** — don't hand-edit them, edit the fragment and rebuild. See `js/business-config.js` (also generated) for the client-side-readable copy of the same data. This fixed real root-relative-path navigation breakage under `file://` and makes the site work identically unopened-via-file, locally served, and deployed to a custom domain.

## 1. Sources

- `logo.png` / `logo-nobg.png` — brand mark. Sampled colors: deep green `#04442C`, gold `#FBBE07`, mid emerald `#2D834D`.

## 2. Data / placeholder handling

Per prompt.md's strict technical requirements, every page uses literal tokens for injection — not resolved values:

- `{{NAME}}` — replaces every literal "Futurefocus Solutions" / "Futurefocus" mention (nav brand, hero, About, footer blurb, compliance line, copyright, WhatsApp default message).
- `{{ADDRESS}}` — replaces the West Mambalam street address block (footer, Contact page). Wrapped in `{{#ADDRESS}}...{{/ADDRESS}}`.
- `{{PHONE}}` — replaces `+91 7550102391` everywhere it appears (top contact bar, footer, Contact page, `tel:` links, floating call button).
- `{{WHATSAPP}}` — replaces `+91 91760 49030` (footer, Contact page, floating WhatsApp button, WhatsApp JS redirect target). Wrapped in `{{#WHATSAPP}}...{{/WHATSAPP}}` for the optional floating WhatsApp button and footer line.
- `{{EMAIL}}` — replaces `support@futurefocussolutions.in` everywhere (top contact bar, footer, Contact page). New token added per user request; not in the original prompt.md list but follows the same `{{FIELD}}` convention.
- `{{GOOGLE_LINK}}` — used for the Contact page "View on Google Maps" / embed link. Wrapped in `{{#GOOGLE_LINK}}...{{/GOOGLE_LINK}}` since optional.

Everything else — GSTIN, Fax, "Chennai", business hours, all service copy, testimonials, About Us story — stays as literal hardcoded text from website-copy-new-v2.md. No nested conditionals; one level only.

## 4. Visual system

Adapted from DESIGN.md's structural system (spacing scale, radius scale, elevation rules, component shapes) with Futurefocus's own identity, not Binance's literal palette:

**Theme direction (user-approved: "Binance-faithful"):** dark `canvas-dark` body on every marketing page; light footer as the one deliberate inversion (mirrors DESIGN.md's own footer-light-on-dark-body pattern).

**Palette (Tailwind config, extends the reference file's structure):**
- `primary`: `#FBBE07` (brand gold, sampled from logo) — replaces Binance's `#fcd535`
- `primary-active`: `#E0A800` (darker press state)
- `canvas-dark`: `#0A1F16` (deep green-black, not neutral near-black — keeps the dark theme distinctly "ours")
- `canvas-light`: `#FFFFFF`
- `surface-card-dark`: `#12291D`
- `surface-elevated-dark`: `#1B3A28`
- `surface-soft-light`: `#FAFAF5` (warm off-white footer)
- `surface-strong-light`: `#F2F0E6`
- `ink`: `#0F1A14`
- `body`: `#E7ECE8`
- `body-on-light`: `#0F1A14`
- `muted`: `#8AA398`
- `muted-strong`: `#A9BFB2`
- `hairline-on-dark`: `#1B3A28`
- `hairline-on-light`: `#E7ECE8`
- `emerald` (secondary accent): `#2D834D` — used sparingly for trust/positive icons and checkmarks, filling the role DESIGN.md's turquoise plays; never as a CTA background.
- `on-primary`: `#0F1A14` (dark text on gold, mirrors Binance's black-on-yellow rule)
- `info`: `#3b82f6` (focus ring, unchanged from reference)

**Header on dark:** the full-color logo (dark green wordmark) would lose contrast on `canvas-dark`, so the header uses a **white-recolored logo variant** (green → white/cream, gold unchanged) generated from `logo-nobg.png`. Footer uses the original full-color logo (light background, full contrast).

**Typography (per user: use client-approved-reference.html's fonts):**
- Sans: **Inter** (400/500/600/700) — headings, body, nav, buttons.
- Mono: **JetBrains Mono** (500/700) — trust-strip stats ("15+ years", "1,200+ clients"), loan rate/amount figures, any numeric callout. Loaded via the same Google Fonts `<link>` pattern as the reference file.

**Components carried over from DESIGN.md, recolored to the tokens above:** button-primary (gold bg, dark text, `rounded-md`, pill variant for hero CTAs), trust-badge, stat-callout, feature/service card, testimonial card, cta-band-dark, faq-row (used on Insurance's "how to choose cover" if expanded to an accordion), footer-light.

## 5. Technical build patterns (built fresh per prompt.md; only fonts taken from the reference file)

- Sticky header, auto-hide on scroll down / reappear on scroll up, via a small vanilla-JS scroll listener.
- Mobile menu: full-screen overlay sheet with the same nav links as desktop.
- Scroll-to-top floating button: fades in past ~500px scroll, smooth-scrolls to top.
- Floating action stack (bottom-right): scroll-to-top, Call (`tel:{{PHONE}}`), WhatsApp (`https://wa.me/{{WHATSAPP}}`) — all three required by prompt.md requirement 3.
- WhatsApp enquiry form: `e.preventDefault()`, builds a formatted message from Name / Phone / Service dropdown / Message fields, URL-encodes it, opens `https://wa.me/{{WHATSAPP}}?text=...`. Service dropdown options match website-copy-new-v2.md's Contact section: Financial Planning, Retirement & Tax Planning, Insurance, Loans, Real Estate, Debt Collection & Recovery.
- Scroll-triggered motion: `IntersectionObserver`-based fade/slide-in on section entry, applied to cards, stat blocks, and section headings across every page (prompt.md requirement 6: "maximum places").
- All of the above is written once as a shared boilerplate (markup + JS) reused verbatim across all 13 pages for consistency, not copied from any reference file.

## 6. Content mapping

Every page's copy comes directly from the matching section of `website-copy-new-v2.md` (Home, About Us, Services landing, and the six service pages, Testimonials, Contact — including its 5 drafted testimonials, reused for both the Home teaser (2) and the full Testimonials page (all 5), satisfying prompt.md's "5-6 testimonials" requirement). Footer, top contact bar, and compliance line come from the copy doc's "Global elements" section with tokens substituted per §2.

**Privacy Policy and Terms & Conditions** are not in the copy doc — write standard India-appropriate boilerplate for a financial-services intermediary (data collected via the enquiry form, WhatsApp redirect disclosure, no cookie tracking beyond basic analytics, third-party product disclaimers consistent with the existing compliance line, governing-law/Chennai-jurisdiction clause) in the same plain, direct voice as the rest of the site. Link both from the footer's Legal area (new column, alongside existing Quick Links/Services columns).

## 7. Images

Sourced from Unsplash/Pexels (free-license), downloaded into `/assets/images/` (not hotlinked), demographically-neutral, one per relevant section per page (hero, about, each service card, testimonials avatars as initials-only per the reference pattern rather than stock headshots). `alt` text attributes author + source per prompt.md requirement 2, e.g. `alt="Photo by [Author] on Unsplash - [description]"`.

## 8. Out of scope

- CMS/backend, real form submission/email delivery (WhatsApp redirect only, per copy doc).
- Legal review of the compliance line or verification of invented stats/testimonials — flagged in the copy doc's own Draft data log, unchanged here.
- Google Maps API key / live embed — uses the `{{GOOGLE_LINK}}` conditional link pattern instead, matching the reference file's "View on Google Maps" card treatment.
- Git commit of this spec — this project directory is not a git repository.
